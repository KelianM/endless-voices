# Dataset licensing notice

The source-derived conversation dataset in `data/pilot-v1/` is distributed under
GPL-3.0-or-later. The dataset includes dialogue from Endless Sky and agent-authored context
and annotations for Endless Voices.

The [licensing bundle](data/pilot-v1/licensing/) contains the full license, upstream copyright
inventory, contributor credits, selected source notices and dataset attribution. Run
`git lfs pull` to read the complete bundle locally. Preserve the licensing material when
redistributing the dataset.

Python code or determine the license of a future trained adapter.
