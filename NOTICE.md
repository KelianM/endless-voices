# Dataset licensing notice

The dataset in `data/dataset/` contains authored Endless Sky text. Its
[licensing bundle](data/dataset/licensing/) includes the upstream license, copyright
inventory, contributor credits and attribution. These files are stored with the dataset
in Git LFS; run `git lfs pull` to retrieve them. Preserve the notices when redistributing data.

This notice does not assign a license to the repository's Python code or determine the
license of a future trained adapter.
