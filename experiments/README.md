# Experiments

This directory records ad-hoc investigations: runners, inputs, procedures and findings.
Experiments use the shared system machinery. Reusable behavior and regression tests belong
in `src/` and `tests/`. Experiment scripts are research records, not supported system commands.

Model weights, databases and generated outputs stay in ignored `data/local/` or `outputs/`.

[Retrieval embeddings](retrieval-embeddings/README.md) records the comparison of embedding
model sizes and passage versus scene retrieval.
