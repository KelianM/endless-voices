# Architecture decision records

Each record states one design decision with lasting effect on this project: the context that forced it, what was decided, and what follows from it. Small choices and tuning values belong in the code and its history, not here.

A record is not edited once accepted, except to fix a mistake or add a source. When a decision changes, write a new record and set the old one's status to `Superseded by ADR N`. Start a new record from [template.md](template.md), numbered after the last one.
